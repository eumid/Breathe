# Breathe

Учёт лечения по назначению от 08.09.2026 (острый риносинусит, аллергический ринит):
Telegram-бот с напоминаниями, Mini App с прогрессом и календарь как страховка.

Шесть препаратов с курсами от 5 до 28 дней, 15 приёмов в сутки в первые дни.
Бот группирует их в **6 блоков**, а не шлёт 15 отдельных сообщений — иначе его мьютят на третий день.

## Как это работает

```
Cloudflare Worker
├── cron * * * * *  → чей блок наступил → sendMessage с кнопками
├── /tg/<secret>    → вебхук: команды и нажатия кнопок
├── /api/*          → Mini App читает и пишет отметки (подпись initData)
└── статика public/ → Mini App (он же PWA в браузере)
        ↕
   D1 «breathe»: users, marks, sent
```

Напоминание и отметка — одно сообщение: тапнул кнопку прямо из уведомления,
текст перечёркивается, блок закрывается. Никуда переходить не нужно.

| Файл | Назначение |
|---|---|
| `public/schedule.js` | Схема лечения — единственный источник правды. Все правки только здесь. |
| `public/index.html` | Mini App: план по блокам, прогресс, соблюдение. В браузере работает как PWA на `localStorage`. |
| `worker/index.js` | Крон, вебхук, API. |
| `worker/format.js` | Тексты и клавиатуры сообщений. |
| `worker/telegram.js` | Bot API и проверка подписи `initData`. |
| `schema.sql` | Таблицы D1. |
| `tools/gen-ics.mjs` | Генератор `public/breathe.ics`. |
| `tools/test.mjs` | Прогон всего курса поминутно без Telegram и Cloudflare. |
| `tools/setup.mjs` | Помощник установки: спрашивает по-русски и всё настраивает сам. |

## Установка

Есть помощник — он проводит через все шаги, объясняет термины и всё настраивает сам:

```bash
npm install
npm run setup
```

Помощник проверит окружение, заведёт вход в Cloudflare, спросит токен бота,
создаст базу, положит секреты, дважды опубликует воркер (второй раз — уже
с адресом Mini App), пропишет вебхук и проверит, что бот отвечает.
Если что-то упало — запустить повторно, он продолжит с места остановки.

Вручную то же самое:

```bash
npx wrangler login
npx wrangler d1 create breathe          # database_id из вывода → в wrangler.toml
npm run db:init
npx wrangler secret put BOT_TOKEN       # токен от @BotFather
npx wrangler secret put WEBHOOK_SECRET  # openssl rand -hex 32
npm run deploy                          # URL из вывода → MINI_APP_URL в wrangler.toml
npm run deploy
curl "https://breathe.<аккаунт>.workers.dev/setup?key=<WEBHOOK_SECRET>"
```

Проверка живости: `GET /health` — вернёт локальное время Ташкента и номер дня курса.
Проверка сборки без публикации: `npx wrangler deploy --dry-run`.

**Курс начался раньше бота.** При первом `/start` бот присылает блоки сегодняшнего дня,
время которых уже прошло, с обычными кнопками — отметить можно задним числом.
Для прошедших дней — `/catchup 08.09` (принимает также `08.09.2026` и `2026-09-08`);
без аргумента поднимает сегодняшний день. В Mini App то же делает стрелка «‹».

**Ограничить доступ.** Бот многопользовательский: данные разделены по `chat_id`,
чужой не увидит твои отметки, но может завести себе учёт по этой же схеме.
Если не нужно — добавь проверку `chat` по списку в `onUpdate`.

## Календарь как страховка

`public/breathe.ics` — те же блоки, стоп-напоминания и визит к врачу.
Импортировать стоит хотя бы ради визита: Telegram можно замьютить или пропустить
в потоке чатов, а календарный алерт пробивает Фокус на iPhone.

После деплоя файл отдаётся воркером по адресу `/breathe.ics` — ссылку достаточно
открыть в Safari, и она уйдёт прямо в Календарь. Локальный файл тоже годится, но
встроенные смотрелки сторонних приложений (Telegram, Яндекс.Браузер) показывают
содержимое без кнопки «Добавить все» — тогда «Поделиться» → «Календарь».

Перед повторным импортом старый календарь удалить, иначе события задвоятся.

## Расписание

Старт 08.09.2026, контроль 22.09.2026 (Ибрагимов Жасур Нодирович).
Утром и вечером порядок жёсткий: **Риноксил → через 5 минут душ → сразу гормональный спрей**.

| Блок | Время | Состав |
|---|---|---|
| 🌅 Утро | 08:00 | Риноксил → душ → Авамис → Синупрет |
| 🧴 Мазь | 10:00 | Метилурацил |
| 🕐 День | 13:30 | душ → Синупрет |
| 🕓 Полдник | 16:00 | душ → Метилурацил |
| 🌆 Вечер | 20:00 | Риноксил → душ → Авамис → Синупрет |
| 🌙 Ночь | 22:00 | Метилурацил → Л-Монтус |
| 🛑 | 21:30 | «завтра НЕ принимать» в последний день курса |
| 🌗 | 23:00 | догон по неотмеченному |

Итог по назначению: Риноксил 2 р/д × 5 дней, душ 4 р/д × 14, спрей 2 р/д × 28,
Л-Монтус 1 р/д × 14, Метилурацил 3 р/д × 14, Синупрет 3 р/д × 10.
Часов врач не назначал — время подобрано так, чтобы выдержать цепочку и развести мазь со спреем.
Меняется в `public/schedule.js`, после чего `npm run ics` и `npm run deploy`.

Диета на весь курс: острое, сладкое, солёное, цитрусовое — нельзя.

## Тесты

```bash
npm test
```

Симулирует все 28 дней поминутно на `node:sqlite` с перехваченным Bot API и проверяет:
каждый блок ушёл ровно один раз, стоп-предупреждения не задвоились и не потерялись,
кнопки ставят и снимают отметки, «Всё принял» закрывает блок, дозировки за курс
совпадают с назначением, нагрузка не превышает 9 сообщений в самый плотный день,
первый запуск посреди дня предлагает отметить прошедшие блоки и не даёт крону их
продублировать, `/catchup` с датой поднимает нужный день и отклоняет дату вне курса.

## Где легко ошибиться

- **Риноксил — ровно 5 дней.** Сосудосуживающий; дольше — медикаментозный ринит.
  Бот предупреждает за день и присылает стоп 12.09.
- **Гормональный спрей — все 28 дней.** Эффект накопительный, к 7-му дню становится
  лучше, и именно тогда курс обычно бросают. Он на две недели длиннее остальных.
- **Душ до спрея, а не после** — иначе смываешь препарат.
- **Мазь не сразу после спрея** — мешает всасыванию, поэтому она в отдельных блоках.
- **Замьюченный бот = нет напоминаний.** Для этого и нужен `.ics` на визит к врачу.

Приложение не заменяет назначение врача — оно ведёт учёт того, что уже назначено.
