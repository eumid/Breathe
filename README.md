# Breathe

Трекер приёма лекарств по назначению от 08.09.2026 (острый риносинусит, аллергический ринит).
Считает дозы по дням, показывает, когда препарат нужно прекратить, и напоминает о контрольном приёме.

## Что внутри

| Файл | Назначение |
|---|---|
| `schedule.js` | Схема лечения — единственный источник правды. Все правки только здесь. |
| `index.html` | Приложение: план дня, галочки, счётчики, соблюдение за 14 дней. Данные в `localStorage`. |
| `breathe.ics` | Календарь напоминаний: каждый приём + стоп-уведомления + визит к врачу. |
| `tools/gen-ics.mjs` | Генератор `breathe.ics` из `schedule.js`. |
| `tools/gen-icon.mjs` | Генератор иконки `icon-180.png`. |
| `sw.js`, `manifest.webmanifest` | Офлайн-режим и установка на домашний экран. |

## Установка на iPhone

1. **Напоминания.** Открыть `breathe.ics` на телефоне (AirDrop, почта или ссылка) → «Добавить все» в Календарь.
   Каждое событие с алертом в момент приёма; серии заканчиваются сами в последний день курса.
   Вечером последнего дня приходит отдельное «Завтра НЕ принимать: …».
   Визит к врачу — с напоминанием за сутки.
2. **Трекер.** Открыть страницу в Safari → «Поделиться» → «На экран „Домой“».
   Дальше работает офлайн, отметки хранятся на устройстве.

Хостинг — GitHub Pages: Settings → Pages → Source: ветка с этим кодом, папка `/`.
Файлы должны отдаваться по HTTP: `schedule.js` подключается как ES-модуль, с `file://` не запустится.

## Пересборка после правок схемы

```bash
node tools/gen-ics.mjs   # перегенерировать календарь
node tools/gen-icon.mjs  # перегенерировать иконку (нужно редко)
```

Старый календарь перед импортом нового удалить, иначе события задвоятся.

## Схема лечения

Старт 08.09.2026. Утром и вечером порядок жёсткий: Риноксил → через 5 мин носовой душ → сразу гормональный спрей.

| № | Препарат | Режим | Курс | По |
|---|---|---|---|---|
| 1 | Риноксил 0,05% спрей | 2 дозы в каждую ноздрю, 08:00 и 20:00 | 5 дней | 12.09 |
| 2 | Носовой душ (Аквалор софт / Аквамарис норм) | 08:05, 13:00, 17:00, 20:05 — назначено 3–4 раза | 14 дней | 21.09 |
| 3 | Авамис / Флутинекс / Флутел / Фронза | 2 дозы, 08:10 и 20:10 | 28 дней | 05.10 |
| 4 | Л-Монтус / Аллервей М | 1 таб. перед сном, 22:30 | 14 дней | 21.09 |
| 5 | Метилурацил мазь | в каждую ноздрю, 09:30, 15:00, 22:00 | 14 дней | 21.09 |
| 6 | Синупрет экстракт | 1 таб., 09:00, 14:00, 21:00 | 10 дней | 17.09 |

Диета на весь курс: острое, сладкое, солёное, цитрусовое — нельзя.
Контрольный приём: **22.09.2026**, Ибрагимов Жасур Нодирович.

Время слотов расставлено так, чтобы разнести приёмы; врач конкретных часов не назначал —
менять под свой день можно в `schedule.js`, соблюдая порядок утренней и вечерней цепочки.

## Где легко ошибиться

- **Риноксил — ровно 5 дней.** Сосудосуживающий; дольше — медикаментозный ринит, слезать тяжело.
  В приложении на 4-й день предупреждение, на 5-й — стоп-баннер.
- **Гормональный спрей — все 28 дней.** Эффект накопительный, к 7-му дню становится лучше,
  и именно тогда курс обычно бросают. Он длиннее всех остальных на две недели.
- **Душ до спрея, а не после.** Промывание после спрея смывает препарат.
- **Мазь не сразу после спрея** — иначе мешает всасыванию; для неё отдельные слоты.

Приложение не заменяет назначение врача и не даёт медицинских рекомендаций —
оно только ведёт учёт того, что уже назначено.
